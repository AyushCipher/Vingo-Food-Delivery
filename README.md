# Vingo-Food-Delivery

A full-stack food delivery platform with user, restaurant owner, and delivery boy panels. Features include real-time order tracking, Razorpay payment integration, and a unique "Food Reels" feature—allowing users and owners to upload, showcase, and interact with short video reels of dishes. The platform supports order management, reviews, shop dashboards, and delivery assignment tracking for a seamless experience.

## Website Features

### User Panel
- Browse shops and food items by city
- Add items to cart and place orders
- Track order status in real-time
- View and interact with food reels
- Leave reviews and ratings for shops and items
- Manage profile and order history

### Restaurant Owner Panel
- Manage shop details and menu items
- Upload and showcase food reels for promotion
- View and manage incoming orders
- Track pending and delivered orders
- Access dashboard analytics

### Delivery Boy Panel
- Receive and accept delivery assignments
- Real-time order tracking and location updates
- OTP-based order completion
- Payment feature with conditional payouts
- View delivery statistics and earnings

### Food Reels Feature
- Upload short video reels for dishes
- Showcase featured items in reels
- Like, comment, and save reels
- Edit and delete reels

### General Features
- Secure authentication for all roles
- Responsive design for desktop and mobile
- Email notifications for order updates
- Razorpay payment integration
- Error handling and user-friendly notifications
